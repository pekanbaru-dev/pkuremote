# Security Policy

## Supported Versions

Only the latest release of PKU Remote receives security updates.

## Reporting a Vulnerability

Please report security vulnerabilities through **GitHub's private vulnerability reporting** feature:

1. Go to the [PKU Remote repository](https://github.com/pekanbaru-dev/pkuremote)
2. Click **Security** > **Report a vulnerability**
3. Fill in the report with the following information:

   - **Affected version** — the release or commit where the vulnerability exists
   - **Description** — what the vulnerability is and how it can be exploited
   - **Steps to reproduce** — a minimal, reproducible sequence of actions
   - **Impact** — what an attacker could gain by exploiting it
   - **Suggested fix (optional)** — if you have a patch in mind

Do **not** report security vulnerabilities via public GitHub issues, pull requests, or discussions.

## Response

You can expect an initial acknowledgment within 72 hours. We will work with you to understand the issue, assess its severity, and coordinate a fix and disclosure timeline.
